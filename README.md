# 全视之眼 (Eye of Omniscience) v1.4.3

「全视之眼」是为 SillyTavern 设计的扩展工具。它在角色卡的基础上叠加了一层元设定，让你能够脱离角色卡的既定框架，实时调整世界观、修正角色人设、监视特定角色状态、下达最高指令、以提示词指导AI生成结构化的设定。

**免责说明**：本扩展本质上是一套提示词约束逻辑，其效果的稳定性高度依赖于底层模型对指令的遵循能力。模型越听话，设定执行越稳。

## 核心能力

### 1. 设定修正

通过定义「世设」和「人设」条目，覆盖原卡设定。支持分层级管理（系统机制、后宫、NSFW、叙事节奏等），AI 会优先响应这些更高级别的指令。

- **存为自定义**：每条世设右侧设有书签按钮，点击即可将该条目连同其下的子项保存为自定义条目，供日后调用。保存前会弹出命名窗口，名称可以自行填写。
- **导入时提示重复**：导入的内容与已保存内容存在重复时，先给出提示，可选择追加、替换或取消，不会直接覆盖原有内容。导入的条目在保存为自定义之前同样可以逐条命名。

### 2. 实时监控

将角色加入监视名单，AI 的回复将附带该角色的状态表单（位置 / 行为 / 外貌 / 服装 / 状态 / 心意）。

- **真实记录**：覆盖从高光时刻到日常琐事的全流程。
- **视角隔离**：仅当角色在正文中出场时，监控内容才会以角色视角同步展示；否则，监控仅保留在后台档案中。
- **注意**：正文看不见监控块是隐藏正则的作用，并非没生成，你可以在「档案」页查看完整记录。

### 3. 最高指令

为角色下达具体指令。AI 会补全中间的执行逻辑。若目标不在当前视角，执行过程仅出现在后台档案，不会突兀地中断当前对话。

### 4. 设定生成

在「设定」页右上角点钢笔按钮进入设定生成页。写下你要的设定要求，填好名称、类型、范围、NSFW、状态机，点「发送」——这段内容会追加到聊天输入栏，按回车发出去，AI 会停下手上的创作，只按内置的八步流程产出一份设定。

- **只管这一轮**：这一轮不写正文、不推进剧情，只出设定和意见。
- **产出能直接用**：一段带标签的 yaml，复制后粘到「设定」页的「内容」框里，会自动拆成树形条目存进去，同时逐条存进自定义条目，不用手工敲层级。
- **目前只支持世设**：人设那一项在下拉里是灰的，暂时选不了。

## 安装与更新

**安装要求**：SillyTavern 1.18.0（其他版本未经测试）；不需要安装「酒馆助手」这个前置扩展。

### 安装方式（选一）

1. **推荐（扩展面板）**：在 SillyTavern 扩展页面的输入框中直接填入 GitHub 仓库地址，点击安装。安装后可直接使用扩展面板的「Update」按钮更新。
2. **ZIP 解压**：下载仓库，解压并将文件夹重命名为 `SillyTavern-Eye-of-Omniscience`（GitHub 下载的压缩包通常带 `-main` 后缀，去掉它），放入 `extensions/` 目录。

    > 目录内应直接包含 `manifest.json`，不可多套一层文件夹。

### 安装后必备步骤

1. 刷新酒馆页面（Ctrl+F5）。
2. 在扩展页面找到「**全视之眼 · 安装与更新**」，点击「**安装所选**」（此操作将规则写入世界书）。
3. 安装后，世界书会自动设置为全局启用。

## 功能节点详解

点击屏幕上的眼睛图标可展开六个节点：

- **记录**：管理监视名单。每个名单为独立词条。
  - 名字后图标：
    - 眼睛（查看档案）
    - 笔（改名）
    - 叉（移出）
- **档案**：按楼层回看角色的历史监控记录。支持角色置顶，页码双击可跳转，支持「上一楼 / 下一楼」翻页。
- **设定**：创建「世设」和「人设」条目。
  - **普通栏**：直接填入大标题与内容，点击「保存」或「加入」。
  - **复合栏（可选）**：使用「＋同级」「＋下级」搭建嵌套结构。
  - **整份粘贴**：把 AI 产出的设定（带代码块的那种）直接粘进「内容」框，会按标签和缩进自动拆成多层条目写进当前卡；普通一句话粘贴还是原来的单条逻辑。
  - **右上角钢笔**：进入「设定生成」页。
- **指令**：编写并发送指令（奖赏、惩罚、改造、洗脑）。
- **设置**：配置扩展偏好。
- **说明**：内置详细使用说明。

### 核心技巧

- **保存与加入**：「保存」仅存入自定义词条以便复用（不生效）；「加入」才会真正写入世界书。
- **启用控制**：扩展面板仅负责条目的创建与管理。需在**酒馆自带的世界书面板**中勾选条目，才可使其参与注入。
- **AI 强力唤醒**：在启用列表右侧点击“发送”小图标，可将条目内容追加到聊天输入栏，需手动按回车发送。
- **输入强化**：在每轮回复前插入隐藏标记。**注意**：编辑框和聊天记录中不会看到此标记，这是正常设计。

### 设置页说明

| 分组 | 开关 | 说明 |
| :--- | :--- | :--- |
| — | 全视之眼 | 总开关。关掉后词条改为关键词触发，不再常驻注入 |
| 功能开关 | 监控 / 设定 / 指令 | 关掉哪个，对应的节点就变灰不可点，其管辖的词条也不再常驻 |
| 功能强化 | 强力模式 | 在「角色定义之后」和「对话最末 · 深度 0」之间整体切换，排查“设定不生效”的首选方案 |
| 功能强化 | 输入强化 | 在发给 AI 的内容最前面加隐藏标记 |
| 显示 | 菜单分离 | 面板脱离悬浮球，自由拖拽 |
| 显示 | 简化动画 | 六芒星菜单动画加速 |

## 数据与更新

- **数据存储**：
  - **世界书条目**：5 条固定规则（全视之眼、设定修正、实时监控、最高指令、设定生成）。自定义条目带 `世设-`、`人设-`、`监视对象-` 前缀。
  - **本地存储**：面板配置、设置项保存在浏览器的 localStorage 中（以 `dg_eye_` 开头）。
- **多卡管理**：数据按角色卡独立存储。切换角色卡后若设定「看起来没了」，不要慌，换回原来的卡数据还在。
- **更新方式**：使用扩展面板的 Update 按钮更新后刷新。若规则有变或内容、配置被改动，安装清单会显示「配置错误」，可对比后手动选择更新为最新的官方版本。

## 常见问题 (FAQ)

1. **看不到悬浮球？** 检查旧版「**酒馆助手**」脚本是否仍在运行。有冲突时本扩展会**让位不启动**，请先关闭旧脚本后再刷新。
2. **设定没生效？** 依次确认：世界书是否设为全局启用、设置页总开关是否打开、酒馆世界书面板中是否勾选了该词条、五条规则词条是否启用。
3. **卸载四步**：
   1. 删除 `extensions/SillyTavern-Eye-of-Omniscience` 文件夹。
   2. 删除世界书中的五条固定规则，以及所有带前缀的自定义条目。
   3. 正则面板删除「全视之眼-隐藏监控内容」。
   4. 控制台执行 `localStorage` 清理 `dg_eye_` 数据。

## 已知局限

- 图片消息不触发输入强化；文字补全模式下靠原文定位用户消息，预设若做过额外加工可能定位不到。
- 弱模型可能输出不完整，或只执行一半指令；设定条目常驻上下文，写得越多 Token 消耗越多。
